# Contabilidad Ferretería - Project Instructions

## Overview
Multi-tenant accounting and HR web application for a hardware store (Ferretería El Paisa), deployed at libromono123.digital.

## Tech Stack
- Next.js 14 (App Router), React 18, Tailwind CSS
- PostgreSQL with Prisma ORM
- NextAuth.js v4 for authentication
- Abacus LLM API (GPT-4.1-mini) for AI features

## Modules
1. **Dashboard** (`/`) - Main stats, navigation
2. **Empresas** (`/empresas`) - Company management
3. **Facturas** (`/facturas`) - Invoice management
4. **Reportes** (`/reportes`) - Reports
5. **Retefuente** (`/retefuente`) - Retention management with historical thresholds (2024-2026)
6. **Saldos** (`/saldos`) - Balance tracking
7. **RH** (`/rh`) - HR module (employees, payroll, shifts, settlements)
8. **Contador IA** (`/contador-ia`) - AI accountant with chat, document generation, DB actions
9. **IA Exógena** (`/ia-exogena`) - AI assistant for Colombian tax Exógena report (Medios Magnéticos)
10. **Admin** (`/admin/usuarios`) - User management panel

## Key Design Decisions
- Color scheme: Blue/Purple gradient for Contador IA, Emerald/Teal for IA Exógena
- Firmante name: "BLANCA ODILA GOMEZ OCAMPO" (NOT "OLALA")
- NIT del emisor: 32390784-4
- Colombian currency format throughout
- Streaming LLM responses for chat interfaces
- DOCX generation with PizZip, PDF via Abacus HTML2PDF API

## IA Exógena Module
- Routes: `/ia-exogena`, `/api/ia-exogena/chat`, `/api/ia-exogena/generate-report`, `/api/ia-exogena/process-excel`
- Supports formats: 1001 (Pagos), 1003 (Retenciones), 1005 (IVA Descontable), 1006 (IVA Generado), 1007 (Ingresos), 1008 (CxC), 1009 (CxP), 2276 (Rentas Trabajo)
- UVT values: 2024=47065, 2025=49799, 2026=52631
- Integrates system data: invoices, companies, employees/payroll, balances
- Excel report generation with xlsx library
- File upload support up to 50MB

## User Preferences
- Language: Spanish (Colombian)
